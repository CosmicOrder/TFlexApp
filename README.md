# TFlexApp — генератор 3D-моделей и чертежей деталей для T-Flex CAD 17

Приложение создаёт 3D-модель прямоугольной детали с опциональным отверстием и автоматически формирует чертёж с тремя проекциями:

- три стандартные проекции (главный вид, вид слева, вид сверху)
- линейные размеры: длина, высота, толщина
- диаметральный размер отверстия
- основная надпись (форматка ГОСТ 2.104-68) с обозначением, наименованием и масштабом
- единый масштаб видов по ГОСТ 2.302-68

## Требования

- Windows x64
- Установленный T-Flex CAD 17
- .NET 10 SDK

## Сборка и запуск

```bash
dotnet build
dotnet run
```

Или открыть `TFlexApp.slnx` в Visual Studio и нажать F5.

## Архитектура

Приложение построено по паттерну **MVP (Model-View-Presenter)** с **Facade** для изоляции T-Flex API:

- **Model** (`Model.cs`) — данные детали: габариты, отверстие, обозначение
- **View** (`IView` / `Form1`) — пользовательский интерфейс, пассивная форма с полями ввода
- **Presenter** (`Presenter.cs`) — координация: валидация входных данных, вызов CAD-фасада, отображение результата
- **CadFacade** (`CadFacade.cs` / `ICadFacade.cs`) — фасад над T-Flex CAD API: построение 3D-модели, размещение проекций, простановка размеров, заполнение штампа

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `Program.cs` | Точка входа, инициализация T-Flex API, обработка крахов |

| `Model.cs` | Модель детали (DTO) |
| `IView.cs` | Интерфейс представления |

| `Presenter.cs` | Презентер: валидация, координация View и CadFacade |
| `ICadFacade.cs` | Интерфейс фасада CAD-операций |
| `CadFacade.cs` | Реализация: 3D-модель, проекции, размеры, форматка |
| `Messages.cs` | Тексты сообщений для пользователя |
| `TFlexPlugin/` | Проект DLL-плагина для T-Flex CAD (.NET Framework 4.7.2) |
| `TFlexPlugin/Plugin.cs` | Точка входа плагина: `PluginFactory` и `Plugin` с командой «Построить деталь» |
| `TFlexPlugin/TFlexPlugin.tfa` | Файл регистрации плагина в T-Flex CAD |

## Публикация

```bash
dotnet publish -c Release -r win-x64 --self-contained false
```

Готовая сборка — в `bin\Release\net10.0-windows\win-x64\publish\`. Скопируйте всю папку.

На целевой машине нужны:
- .NET 10 Desktop Runtime
- Установленный T-Flex CAD 17

## Сборка в виде плагина T-Flex CAD

Проект можно собрать как DLL-плагин для загрузки непосредственно в T-Flex CAD. Плагин регистрируется в системе приложений T-Flex CAD и запускается командой из ленты или меню.

### Требования

- .NET SDK (для сборки через `dotnet`)
- Установленный T-Flex CAD 17 (DLL плагина — .NET Framework 4.7.2)

### Сборка

```bash
dotnet build TFlexPlugin\TFlexPlugin.csproj -c Release
```

Готовая DLL и файл регистрации — в `TFlexPlugin\bin\Release\net472\`:

- `TFlexPlugin.dll` — библиотека плагина
- `TFlexPlugin.tfa` — файл регистрации в T-Flex CAD

### Установка плагина в T-Flex CAD

1. Скопируйте `TFlexPlugin.dll` и `TFlexPlugin.tfa` в одну папку
2. На ленте во вкладке **Приложения** нажмите «Приложения»
3. В открывшемся окне нажмите кнопку **Добавить**
4. Укажите папку с файлами плагина
5. Выберите «TFlexApp - Генератор деталей» и нажмите **ОК**
6. Нажмите **Запустить**
7. На ленте во вкладке **Приложения** появится кнопка «Построить деталь»

## Использование

### Автономное приложение

1. Запустите приложение
2. Введите габариты детали: длина, высота, толщина
3. При необходимости отметьте «Отверстие» и укажите диаметр
4. Нажмите «Построить» — модель и чертёж отобразится во встроенном окне T-Flex Control

### Плагин T-Flex CAD

1. На ленте во вкладке **Приложения** нажмите «Построить деталь»
2. Введите габариты детали: длина, высота, толщина
3. При необходимости отметьте «Отверстие» и укажите диаметр
4. Нажмите «Построить» — модель и чертёж отобразится во встроенном окне T-Flex Control. 
5. После закрытия окна плагина модель и чертеж появятся в T-Flex CAD.
